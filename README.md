# Learning-Based Control for Mobility Systems

*Approximate Dynamic Programming, Reinforcement Learning, and Online Lookahead*

This repository distributes the evolving textbook for the Fall 2026 course
taught by Kyunghwan Choi at the Korea Advanced Institute of Science and
Technology (KAIST). Chapters are released cumulatively as they are taught.

## Current draft

- Version: `0.7.0-draft`
- Release date: 2026-08-31
- Public coverage: Chapter 1
- [Read or download the current PDF](https://kyunghwan-choi.github.io/learning-based-control-mobility/learning-based-control-mobility-v0.7.0-draft.pdf)
- [Open the textbook landing page](https://kyunghwan-choi.github.io/learning-based-control-mobility/)

The manuscript is an evolving working draft. Content, notation, chapter
coverage, and pagination may change between versions. Use a tagged GitHub
Release when citing a fixed version.
