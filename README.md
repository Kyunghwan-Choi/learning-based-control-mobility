# Learning-Based Control for Mobility Systems

*Approximate Dynamic Programming, Reinforcement Learning, and Online Lookahead*

This repository distributes reviewed teaching units from the evolving textbook
for the Fall 2026 course taught by Kyunghwan Choi at the Korea Advanced
Institute of Science and Technology (KAIST). Each unit is released as a
separate PDF as it is taught; the complete manuscript remains under revision.

## Current draft

- Public collection version: `0.11.0-draft`
- Latest update: 2026-10-08

- [Chapter 3 — Parametric Approximation](https://kyunghwan-choi.github.io/learning-based-control-mobility/learning-based-control-mobility-ch03-v0.10.0-draft.pdf) (30 pages)

The manuscript is an evolving working draft. Content, notation, chapter
coverage, and pagination may change between versions. When citing a teaching
unit, include its versioned PDF URL; tagged GitHub Releases may be used for
